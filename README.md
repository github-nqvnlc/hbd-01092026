### 3. 🎂 Thổi Nến Bánh Kem Sinh Nhật Tương Tác 3D

- Bắn pháo hoa Confetti rực rỡ và bung nở bức thông điệp chúc ước ngọt ngào.

### 4. 📸 Thư Viện 15 Khoảnh Khắc Tình Yêu (`Polaroid Carousel & Lightbox`)

## 🚀 Hướng Dẫn Cài Đặt & Triển Khai

### 1. Chạy trên môi trường Local

Mở trực tiếp tệp `index.html` trên trình duyệt hoặc sử dụng Live Server:

```bash
# Sử dụng npx serve hoặc VS Code Live Server
npx -y serve .
```

### 2. Triển khai lên Cloudflare Workers

Dự án được cấu hình sẵn với `wrangler.toml`:

```toml
name = "hpbd-01092026"
compatibility_date = "2024-09-01"

[assets]
directory = "."
```

Chạy lệnh deploy với Wrangler:

```bash
# Đăng nhập và triển khai tự động lên Cloudflare Edge
npx wrangler deploy
```
